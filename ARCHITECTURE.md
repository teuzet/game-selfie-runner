# Архитектура (заполняется техлидом при старте игры)

## Слои
1. `Game.Core` — чистая симуляция: `Simulation.Step(TickInputs)`; состояние сериализуемо, есть `StateHash()`.
2. `Unity` — адаптер: читает `Simulation.State`, рисует примитивами, собирает ввод в `TickInputs`.

## Детерминизм
- Фиксированный шаг (`TicksPerSecond`), целочисленная/fixed-point математика.
- Lockstep-мультиплеер возможен без изменений ядра: одинаковые входы → одинаковые хэши.
