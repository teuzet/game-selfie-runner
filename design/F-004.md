# F-004. Чат стрима: 17 поводов, волны, база фраз RU/EN

## Зачем
Чат — второй «экран» игрока: он подсказывает дорогу и сразу показывает, что зрители думают о твоём манёвре или фейле. Счётчик зрителей объясняется словами (`design/overview.md`: «Подсказки чата», «Экономика стрима», «Контент M1» — поводы чата и фразы).

## Поведение
1. **Чей чат.** На экране только чат стрима локального бегуна. Повод запускается событием ядра или условием по состоянию этого бегуна (таблица «Поводы»). У ботов чата нет. Формулировку Unity выбирает локально, по сети она не ходит.
2. **Волна.** Повод запускает волну: интенсивность `пик × k` сообщений в секунду держится `держится` секунд, потом линейно падает до 0 за `спад` секунд. Площадь под кривой — `A(t)`. Сообщение номер `n` (`n = 0, 1, …`) выходит в момент, когда `A(t) = n`, то есть первое — сразу. Всего сообщений `N = ceil(k × пик × (держится + спад / 2))`. Так число сообщений проверяется тестом, а случайны только тексты.
3. **Множитель зрителей** `k = clamp(зрители / 500, 0.5, 1.5)`: стрим на 100 зрителей шепчет, на 750 и больше орёт. На подсказку `k` не действует.
4. **Состав.** Тип каждого сообщения волны выбирается по долям повода: поддержка, злорадство или троллинг — фраза повода с таким `mood`; эмодзи — запись из `emoji.json` с тегом повода; спам — символ повода, повторённый 3–6 раз (`💀💀💀💀`). Если подходящей фразы нет, берётся эмодзи.
5. **Фон.** Болтовня из `background.json` и эмодзи идёт всегда: `clamp(зрители / 250, 0.2, 3.0)` сообщений в секунду (100 зр. → 0.4/с, 500 → 2/с, 750+ → 3/с) с интервалами ±30% от среднего. Пока идёт любая волна, фон ×0.5. Во время «нет сигнала» фона нет, волна «подброшен» продолжается поверх помех.
6. **Подсказка** (`HintEvent`: тип, сторона). Сразу выходит одна фраза из `hint.json` по паре тип × сторона, с иконкой препятствия, с подсветкой. Её никогда не выкидывают. Ещё 2 сообщения за 0.8 с: 50% — другая фраза той же пары («чат повторяет»), 50% — `⚠️`-эмодзи. Сторона дана от лица бегуна (его лево), чат не знает, врёт ли подсказка.
7. **Наложение.** Разные поводы в одном тике стартуют вместе, первым выходит старший по приоритету. Тот же повод, пока его волна идёт, перезапускает её с начала (два столкновения подряд не дают двойную волну). Потолок — 10 сообщений за любую секунду. Сверх потолка выкидываются сообщения младшего источника. Приоритет: подсказка > подброшен > финиш > квест выполнен/провален > подножка > столкновение > толкнул > кадр > встал > квест выдан/истекает > рекорд > финиш скоро > зоны > фон.
8. **Выбор фразы.** Случайный по весу `w` среди фраз нужного языка, повода, `mood` (и роли, типа, стороны, квеста, если они заданы). Фраза не повторяется среди последних 15 сообщений. Фразу с подстановкой, для которой у события нет данных, пропускают. Ник — случайный из `nicks.json`, два раза подряд один ник не пишет.
9. **Язык** `ru`/`en` берётся из настройки и действует со следующего сообщения. Уже показанные строки не переводятся.

Почему так: самые громкие волны — у подброса и финиша, это главные зрелища забега. У фейлов злорадства больше, чем поддержки: «фейл — контент». В холодной зоне чат троллит от скуки и сам подталкивает вернуться к быку. Гистерезис 1 м и пауза 10 с нужны, чтобы бег по границе зоны не давал спам.

Проверка теста F-044: «подброшен» при 500 зрителях — 16 сообщений за первые 3 с (`A(3) = 6 × 1.5 + (6 + 3) / 2 × 1.5 = 15.75`, `n = 0…15`), 18 за всю волну. При 100 зрителях — 9, при 750+ — 27.

## Контент
Файлы в `design/chat/` (источник правды, Unity копирует в `Unity/Assets/Data/chat/`):

| Файл | Что | Сколько (минимум) |
|---|---|---|
| `<повод>.json` × 16 | фразы поводов 2–17; у `push`, `trip`, `frame` — по ролям | ≥20 на повод (и на роль) × язык; у каждого `mood` с долей > 0 — ≥3 |
| `hint.json` | подсказки: 8 типов × сторона | ≥20 на каждую пару × язык (своих ≥4, остальное — общие шаблоны стороны) |
| `words.json` | формы препятствий (им./вин. падеж, en), иконки, слова сторон | 8 препятствий + пруд, 5 сторон |
| `waves.json` | таблица «Поводы» как данные + теги эмодзи | 17 поводов |
| `emoji.json` | эмодзи-реакции с тегами (laugh, fear, pain, win, bull, bored, love, shock, money, time, wave, warn) | 80 |
| `nicks.json` | ники зрителей, общие для языков | 60 |
| `donations.json` | тексты донатов по причине (`quest`, `tossed`, `pond`, `any`) | 40 на язык |

Стороны подсказки: `left`, `right`, `center` (полоса C; зевака — по своему текущему `x`: < −1 м — `left`, > 1 м — `right`, иначе `center`), `full` (бельё, вся ширина), `zone` (лестница). Пары: столб L/C/R, лоток L/R, бочки L/C/R, дверь L/R, горшки L/C/R, зевака L/C/R, бельё full, лестница zone — 18 пар.

Подстановки: `{name}` — имя другого бегуна из события (кто толкнул, кого обогнать); `{obstacle}` — препятствие в им. падеже, `{obstacle:acc}` — в вин. (ru; в en то же слово); `{side}` — слово стороны. Если плейсхолдер написан заглавными (`{OBSTACLE}`), значение тоже пишется заглавными. Поля фильтра — `role`, `obstacle`, `side`, `quest` (`*` — любое).

Образец записи (`collision.json`, `hint.json`):
```json
{ "occasion": "collision", "phrases": [
  { "lang": "ru", "mood": "gloat", "w": 2, "text": "{obstacle}: 1, стример: 0" },
  { "lang": "en", "mood": "support", "w": 1, "text": "you ok?? that {obstacle} came out of nowhere" } ] }
{ "occasion": "hint", "phrases": [
  { "lang": "ru", "mood": "hint", "w": 3, "obstacle": "pole", "side": "left", "text": "СТОЛБ СЛЕВА!!" },
  { "lang": "en", "mood": "hint", "w": 1, "obstacle": "*", "side": "right", "text": "{OBSTACLE} ON YOUR RIGHT" } ] }
```
К самому стримеру чат обращается на «ты», без имени. `{name}` — всегда кто-то другой. Имя подставляется как ник, без склонения, поэтому фразы ставят его так, чтобы несклоняемый ник читался («у {name}», «{name}, …»).

Род: персонажи разного пола, поэтому ru-фразы о стримере и о `{name}` пишутся без рода — без прошедшего времени и согласованных прилагательных («ты как??», не «живой?»). В en — без he/she, о другом бегуне — they. Глагол рядом с `{obstacle}` тоже не согласуется: у препятствий бывает разное число (бочки, горшки).

Тон: ирония и троллинг можно; мат, оскорбления по признакам (внешность, пол, возраст, национальность), бренды и реальные люди — нельзя. Бабулю дразнят за сумку и скорость, не за возраст.

Сборка: `dotnet run brainstorm/build_chat.cs` собирает `design/chat/*.json` из `brainstorm/raw/*.txt`. Сырьё: секция `[ru role=actor quest=crash obstacle=pole side=left]`, строка `s2|текст` (`s` поддержка, `g` злорадство, `t` троллинг, `h` подсказка; цифра — вес, по умолчанию 1). `waves.json` пишется из таблицы «Поводы», которая продублирована в сборщике.

## Что считать готовым
1. В этом документе у каждого из 17 поводов есть триггер, пик/держится/спад, доли пяти типов сообщений, а фон задан формулой от числа зрителей. Проверка — таблица «Поводы».
2. Формат базы описан, образец есть (раздел «Контент»). Все файлы `design/chat/*.json` читаются как JSON и проходят `dotnet run brainstorm/build_chat.cs -- --check`.
3. Проверка `--check` печатает счётчики и падает, если: на повод (и роль) × язык меньше 20 фраз; у `mood` с долей > 0 в `waves.json` меньше 3 фраз; эмодзи меньше 80; ников меньше 60; донатов меньше 40 на язык; есть неизвестная подстановка или бренд из стоп-листа.
4. В `hint.json` у каждой из 18 пар тип × сторона ≥20 подходящих фраз в ru и в en, из них ≥4 написаны для этого типа.
5. Глазами по `brainstorm/raw/*`: нет мата, оскорблений по признакам, брендов и реальных людей.

## Открытое
- Генерация шла без тула `brainstorm`: в окружении исполнителя его не было. Тексты написал геймдизайнер (агент) прямо в формате сырья, в `brainstorm/raw/`. Перегенерация тулом заменит `raw/`, и JSON пересоберётся тем же сборщиком. Фраз на повод — 20–28, не ≈25 из визитки. Добирать стоит после гребокса, по тем поводам, где повторы бросаются в глаза.
- Реакция твоего чата на чужие фейлы («{name} улетел на рогах») не входит в 17 поводов. Добавим в M2, если лента без неё кажется пустой.
- Знает ли чат, что подсказка соврала («чат подставил»): ядро это знает, но события нет. Пока не делаем.
- Как ядро врёт стороной у `center`/`full`/`zone`: предлагаю F-021 `center` → `left` или `right`, у `full`/`zone` не врать (стороны нет). Нужно «ок» разработчика F-021.
